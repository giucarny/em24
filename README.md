# em24
Public repository for the preparation of Euromanifesto 2024 data. 

Source documents are PDFs, Word files, and images. The pipeline converts them to clean Markdown using [marker-pdf](https://github.com/VikParuchuri/marker).

---

## Repository layout

```
├── scripts/
│   ├── convert_doc_to_docx.py   # Pre-process legacy .doc files → .docx
│   └── convert_to_markdown.py   # Convert all documents → Markdown
├── docs/                        # Project documentation
├── data/                        # NOT committed — see Data section below
│   └── EM2024/
│       ├── pdf/              # Raw source documents, organised by country
│       └── markdown/         # Marker output (generated by the pipeline)
└── pyproject.toml
```

---

## Data

The `data/` directory is not committed to this repository. Documents must be collected manually from GESIS:

1. Download the manifesto documents from GESIS.
2. Place the documents under `data/EM2024/pdf/`, organised in per-country subdirectories (e.g. `data/EM2024/pdf/Germany/`).

## Requirements

| Dependency | Purpose |
|---|---|
| Python ≥ 3.12 | |
| [uv](https://docs.astral.sh/uv/) | Package and environment management |
| LibreOffice | Converting legacy `.doc` files to `.docx` |
| Ghostscript | Repairing malformed PDFs before conversion |
| NVIDIA GPU (recommended) | Accelerates marker-pdf layout detection and OCR |

Install uv if you don't have it:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Install Python dependencies:

```bash
uv sync
```

### GPU setup

marker-pdf uses PyTorch. The `pyproject.toml` is configured to install the CUDA 12.8 build of PyTorch, which requires driver ≥ 520. If you are on CPU only, remove the `[tool.uv]` and `[[tool.uv.index]]` sections from `pyproject.toml` and run `uv sync` again.

## Running the pipeline

### Step 1 — Convert legacy `.doc` files to `.docx`

Some source documents use the older `.doc` format, which marker-pdf does not support directly. Convert them first:

```bash
uv run python scripts/convert_doc_to_docx.py
```

This scans `data/EM2024/pdf/` recursively, converts every `.doc` to `.docx` in-place using LibreOffice, and skips files that already have a `.docx` counterpart.

### Step 2 — Convert all documents to Markdown

```bash
uv run python scripts/convert_to_markdown.py
```

This scans every subdirectory under `data/EM2024/pdf/` that contains at least one supported file, and runs marker-pdf on it. Output is written to the mirrored path under `data/EM2024/markdown/`.

Supported input formats: `.pdf`, `.docx`, `.xlsx`, `.pptx`, `.epub`, `.html`, and common image formats.

The script:
- Skips files that have already been converted (`--skip_existing`)
- Automatically repairs malformed PDFs with Ghostscript before passing them to marker
- Runs with a single GPU worker and small batch sizes to avoid out-of-memory errors

To resume after an interruption, simply re-run the command — already-converted files are skipped.

---

## Notes

- `.doc` files (old binary Word format) must go through Step 1 before Step 2 will process them.
- Image-only PDFs (scanned documents without a text layer) are handled via OCR inside marker-pdf; expect slower processing.
- Conversion speed depends heavily on GPU availability. On an NVIDIA RTX A4000 (16 GB VRAM), a typical 20–30 page manifesto takes roughly 30–60 seconds.
